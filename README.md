

# Sprint 08 – Performance & PWA

A React e-commerce application focused on Web Performance Optimization, infinite scrolling, and offline-first architecture.

## Features

* React.lazy + Suspense for route-level code splitting
* WebP image optimization with explicit dimensions
* Infinite scrolling using IntersectionObserver
* Custom Service Worker
* Cache-First strategy for static assets
* Network-First strategy for API requests
* Offline support with cached data
* IndexedDB queue for offline actions
* Responsive UI

## Tech Stack

* React
* Vite
* React Router
* JavaScript
* Service Worker
* IndexedDB

## Run Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
